## 4. Open Findings (Not Yet Fixed)

Documented transparently rather than hidden, for the next iteration:

1. **`EncryptionService` regenerates its encryption key on every process
   restart** instead of loading a persisted key from environment
   configuration — any data encrypted before a restart becomes
   permanently undecryptable afterward. (High severity — see
   `SECURITY_AUDIT.md`.)
2. **Public `jobs/` list endpoint** inherits the general 100/day
   authenticated-user throttle even for anonymous visitors, which could
   incorrectly block legitimate browsing traffic. (Low severity — first
   identified during QA load testing.)
3. **No HTTPS/SSL** configured yet on the DuckDNS domain — site currently
   served over plain HTTP.
